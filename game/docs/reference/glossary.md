# Glossary

**Rustwater** — current working game/world-thread name and the starting coastal region. Whether it is the final product title is open.

**Mara Reed** — Old Harbor's Harbor Warden, recurring promotional viewpoint character, and current visual face/mascot of Rustwater. Not the player's canonical avatar.

**Discovery** — explicit recorded first knowledge (species/place/relic/etc.) or implicit learned world relationship. Both are progression.

**Capability progression** — progression that changes what a character can perceive/reach/do rather than only increasing a scalar stat.

**Specimen** — an individual caught creature with stable generated dimensions/provenance/history.

**Provenance** — persistent history/context of an individual item/catch: origin, owner, location/time, bait/environment, generator information, disposition, etc.

**World first** — first globally recorded discovery of a subject in authoritative game state.

**Rich Message** — Telegram's structured message format with Rich Text/block/media/action capabilities, used as Rustwater's native game-panel primitive.

**Ephemeral message** — Telegram group message visible only to a specific user and the bot; useful for personalized interaction within a shared group event.

**Inline mode** — classic `@botusername query` interaction where a user selects a bot-provided result to send into a chat.

**Guest Mode** — 2026 Telegram capability allowing a guest-enabled bot to be mentioned and directly answer in supported chats even when it is not a member.

**Semantic Back** — navigation to the conceptual parent screen rather than a stored browser-history stack.

**Group shoal** — current `/fish` chat-local 20-minute social fishing event with one free persistent catch claim per character/cycle.

**Rusted Key** — current special non-fish encounter/object that demonstrates fishing → clue → exploration → new-location progression.

**Harbor Board** — current Old Harbor objectives + rotating contract interface.

**`tdx`** — in-house Rust ergonomic layer over generated TDLib types/requests; part of the product stack and expected to evolve with Telegram.
