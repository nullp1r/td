# Future Systems Backlog

> **Status:** non-committed direction pool

Do not interpret this as an implementation queue. These ideas should become concrete only when the core game earns them.

## Character/specialization

- traits;
- talent trees;
- professions;
- reputation;
- mutually exclusive capability investment;
- multiple characters only if useful.

## Fishing/activity depth

- passive nets/traps;
- richer struggle/behavior families;
- specialized environmental tackle;
- combinations/preparation/enchantment;
- nonliteral “fishing” devices/activities.

## World

- larger connected maps;
- directional travel;
- vehicles;
- hostile biomes;
- dimensions;
- player-built infrastructure;
- environmental interaction between players;
- per-location/per-chat/global events.

## Collection/procedural

- morphology/color/mutations;
- trait combinations;
- generated artifacts;
- generated locations/encounters;
- trophy/display systems;
- trading.

## Interfaces

- Mini App for maps, crafting, inventory, markets, profiles;
- website/companion view;
- richer media/custom emoji where they improve clarity.

## Monetization

- Telegram Stars are the most natural native option to investigate first;
- crypto/external asset systems later;
- NFT/Telegram gift integration may allow unusual catch/bait/item interactions.

Monetization should not gate basic discovery/fun or turn the core progression into pay-to-win.
