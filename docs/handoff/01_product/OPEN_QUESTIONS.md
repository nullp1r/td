# Open Design Questions

> **Status:** deliberately unresolved

These are not omissions to “fix” automatically. They were left open because playtesting or later systems should inform them.

## Character model

- Do multiple characters per account eventually provide meaningful specialization/roleplay, or merely encourage alts to bypass specialization limits?
- What future traits/stats/talents/professions model best supports “no one can master everything” without generic spreadsheet inflation?

## Automation

- How passive should fishing become?
- A deployable net/trap that is checked occasionally sounds compatible with short sessions.
- How far can automation go before it undermines active discovery and social play?
- Could automation itself become a specialization rather than a universal optimal strategy?

## Geography/travel

- When should directional navigation appear?
- Should long-distance travel become a scheduled activity, vehicle system, map route, or combination?
- How do late-game speedups preserve the feeling of a real world instead of making geography irrelevant?

## Economy

- When should player trading/auction/market systems appear?
- How much specimen provenance should influence price/collectability?
- Which resource sinks remain fun rather than maintenance taxes?

## Procedural content

- Which procedural traits should affect actual behavior/value?
- How rare can optional collector outcomes become without mandatory progression feeling unfair?
- When do generated locations/artifacts become worth the added validation/content complexity?

## Social world

- Which systems should be per-chat, per-location, per-region, and global?
- How can players influence shared environments without making one chat's state destructive to others?
- What forms of competition/cooperation fit Telegram's rate limits best?

## Monetization / external assets

- Telegram Stars are a natural future monetization surface.
- Crypto/NFT gift integration remains exploratory.
- Any external-asset system must not make the core game feel pay-to-win or force blockchain concepts into ordinary play.

## Naming/identity

“Rustwater” is the current starting region/world-thread name used by the prototype. The final product/game name has not been established.
