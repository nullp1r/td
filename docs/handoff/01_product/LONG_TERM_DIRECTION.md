# Long-Term Direction

> **Status:** directional, intentionally non-binding

The architecture should be able to grow toward a genuinely enormous game without requiring MVP code to pretend all of these systems already exist.

Potential long-term layers:

- multiple professions/activities beyond fishing;
- talent/trait/profession specialization;
- player economy and trade;
- factions/reputation;
- vehicles and transport;
- player-built infrastructure;
- hostile/special environments;
- supernatural/technological equipment categories;
- dimensions and remote worlds;
- regional/global/per-chat events;
- environmental manipulation;
- generated specimens/artifacts/locations;
- Mini App visual map/inventory/crafting/markets;
- website/companion surfaces;
- Telegram Stars monetization;
- optional external gift/asset integrations.

The core principle is that the same kind of curiosity that makes a new player wonder what is beyond Old Harbor should still exist when a veteran is exploring something absurdly far from ordinary fishing.
