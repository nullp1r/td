1//! Rust source generation from a parsed `TDLib` API schema.
2//!
3//! This crate turns `td_parser::Definition` values into the three modules
4//! consumed by `td_types`: concrete object structs in `types`, tagged result
5//! enums in `enums`, and serializable requests in `fns`.
6//! Generated names deliberately preserve the upstream `TDLib` spelling.
7//!
8//! Generation is deterministic and writes through [`std::fmt::Display`] without
9//! first building a second source tree or intermediate `String`. Primitive wire
10//! representations receive the required Serde adapters, and direct recursive
11//! layout cycles are found with a compact dependency graph. Direct enum references
12//! inside a recursive component are boxed conservatively; vectors already provide
13//! indirection and remain unboxed.
14//!
15//! ```
16//! use td_codegen::compile;
17//!
18//! let source = compile("user id:int64 = User;").expect("valid schema");
19//! assert!(source.contains("pub struct user"));
20//! assert!(source.contains("pub enum User"));
21//! ```
