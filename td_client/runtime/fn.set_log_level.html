pub fn set_log_level(level: i32)
Expand description

Sets TDLib’s process-wide native log verbosity.

TDLib documents levels 0 through 5 for progressively more verbose output, with higher levels up to 1024 enabling additional diagnostics. Its default is 5; this crate does not silently change it. Supply a level supported by the native library.

This controls native logging, not the optional on_error callback. Logs may contain application-sensitive information; choose verbosity and log destinations as application policy.
